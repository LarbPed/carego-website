# CareGo Website

เว็บไซต์โครงการ **CareGo – ดูแลถึงบ้าน พาไปถึงโรงพยาบาล** (รายวิชา BS93114) สร้างจากเนื้อหาในรายงานและภาพต้นแบบแอป
เป็นเว็บ static (HTML/CSS/JavaScript ล้วน) ไม่ต้องติดตั้งอะไร แค่เปิด `index.html` หรืออัปโหลดขึ้นโฮสติ้งใดก็ได้
(GitHub Pages, Netlify, Vercel, Firebase Hosting ฯลฯ)

## โครงสร้างไฟล์

```
carego-website/
├── index.html         หน้าแรก (hero, ปัญหา, บริการ+ราคา, ขั้นตอน, คุณค่า, ตัวอย่างแอป, persona, ความปลอดภัย, FAQ)
├── booking.html       จองบริการ 4 ขั้นตอน + คำนวณราคาสด + ตรวจสอบข้อมูล
├── my-bookings.html   นัดหมายของฉัน: ติดตามสถานะ, ยกเลิก, ปฏิทิน (.ics), พิมพ์ใบยืนยัน, ให้คะแนน
├── about.html         เกี่ยวกับโครงการ: เนื้อหาบทที่ 1–4, อ้างอิง, คณะผู้จัดทำ
├── admin.html         หน้าทีมงาน (โหมดสาธิต): จับคู่ผู้ให้บริการ, เปลี่ยนสถานะ, KPIs, ส่งออก CSV
├── css/style.css      สไตล์ทั้งเว็บ (รองรับมือถือ, ปรับขนาดตัวอักษร, คอนทราสต์สูง, พิมพ์)
├── js/
│   ├── config.js      ★ ตั้งค่า: LINE OA, เบอร์โทร, อีเมล, webhook, เวลาจองล่วงหน้า
│   ├── data.js        ★ ข้อมูลบริการ/ราคา/โรงพยาบาล (แก้ที่เดียว เว็บอัปเดตทั้งหมด)
│   ├── store.js       ระบบข้อมูลการจอง (localStorage), คำนวณราคา, ปฏิทิน .ics
│   ├── layout.js      ส่วนหัว/ท้าย, เมนูมือถือ, ปรับตัวอักษร/คอนทราสต์
│   ├── icons.js       ไอคอน SVG
│   ├── home.js · booking.js · my-bookings.js · admin.js   สคริปต์แต่ละหน้า
└── assets/            โลโก้, ไอคอนแอป, หน้าจอแอปที่ตัดจากภาพต้นแบบ, รูปประกอบจากรายงาน
```

## การทำงาน

- ลูกค้ากรอกฟอร์มที่ `booking.html` → ระบบตรวจสอบข้อมูล (เบอร์โทร, วันที่/เวลาล่วงหน้า ฯลฯ) → บันทึกการจองพร้อมรหัส `CG-yymmdd-XXXX`
- `my-bookings.html` แสดงรายการและไทม์ไลน์สถานะ (รอยืนยัน → ยืนยัน → ออกเดินทาง → โรงพยาบาล → กลับ → เสร็จสิ้น)
- `admin.html` ใช้เปลี่ยนสถานะ/จับคู่ผู้ให้บริการ ถ้าเปิดสองหน้าต่างพร้อมกันจะเห็นสถานะอัปเดตทันที

## ⚠ ข้อจำกัดปัจจุบัน และวิธีใช้งานจริง

เว็บเป็น static จึง **เก็บข้อมูลไว้ในเบราว์เซอร์ของผู้ใช้เท่านั้น** (localStorage) ทีมงานยังไม่เห็นคำขอของลูกค้าคนอื่นโดยอัตโนมัติ
เพื่อรับคำขอจริง ให้เลือกอย่างใดอย่างหนึ่ง (ตั้งค่าใน `js/config.js`):

1. **LINE Official Account** – ใส่ `lineOfficialAccount: '@yourid'` ปุ่ม “ส่งคำขอทาง LINE” จะเปิดแชทพร้อมข้อความสรุปการจอง (ตรงกับแผนระยะเริ่มต้นในรายงาน 4.1)
2. **Webhook** – ใส่ `webhookUrl` (Google Apps Script → Google Sheets, Make, Zapier, Formspree ฯลฯ) ทุกการจองจะถูกส่งเป็น JSON ไปที่ URL นั้น
3. พัฒนาหลังบ้านจริง (Firebase / Supabase ฯลฯ) แล้วแทนฟังก์ชันใน `js/store.js`

หน้า `admin.html` ไม่มีการล็อกอิน ใช้สาธิตเท่านั้น ห้ามใช้เป็นระบบทีมงานจริง

## ข้อมูลที่ควรตรวจสอบก่อนเผยแพร่

- ราคา “เริ่มต้น” ของรถตู้พยาบาล (฿800) / รถพยาบาล (฿1,500) / รถวีลแชร์ (฿1,000) มาจากหน้าจอต้นแบบแอป
- ราคา Home Care, บริการเสริม, ค่าระยะทาง และตัวคูณไปกลับ/หลายจุด เป็น **ราคาตัวอย่าง** แก้ได้ใน `js/data.js`
- ใส่ช่องทางติดต่อจริงใน `js/config.js` (ว่างไว้ = ไม่แสดง)
- รูปคนในหน้าเว็บมาจากรายงาน ตรวจสอบสิทธิ์การใช้งานภาพก่อนเผยแพร่สาธารณะ
